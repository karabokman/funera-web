Opening the files

  • If Excel puts everything in one column, download again with the semicolon separator (Excel in South Africa expects it), or use Data → From Text/CSV.
  • Amounts are plain numbers in rand with two decimals, dates are year-month-day, and times are South African time.
  • Prices include VAT. The payments file works out the VAT part at the current VAT rate, and leaves those columns blank until a VAT number is set in the site settings. If the rate ever changes, older payments need checking by hand.
  • Text that a spreadsheet could mistake for a formula (starting with =, @ or a stray + or -) is given a leading apostrophe so it can never run.
